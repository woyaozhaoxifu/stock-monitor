一、这个版本是什么

实时行情看板是一个零依赖、单文件的 A 股行情桌面小程序：后端用 Python 内置 http.server 起本地服务，前端用 ECharts 画图，数据源接入腾讯财经与东方财富公开接口。双击即可在浏览器（或原生桌面窗口）里查看大盘指数、自选股、板块涨幅、涨跌家数、龙虎榜与个股分时/K 线。

  • 应用名称：从本版起，全站统一命名为 「詹姆斯是goat」（窗口标题、页面标题、默认配置、README 一致）。
  • 版本号：由 v2.10 升级到 v3.0。
  • 一句话定位：把 K 线看清楚、把日期滑到底，本地零配置开箱即用，也能一键部署上线。

2.1 应用命名统一为「詹姆斯是goat」

页面 <title>、界面 <h1> 大标题、原生窗口标题、config.example.json 默认标题、以及 README.md 全部统一为「实时行情看板 · 詹姆斯是goat」。用户若已配置 config.json 里的 title，以用户配置为准（本次已为你预置为新名称）。

2.2 个股 K 线图大幅放大

点开任意个股弹窗后，K 线图高度由 230px 提升到 460px，弹窗整体宽度由 780px 放宽到 1060px，单根 K 线更宽、更清晰，便于看清量价细节。

2.3 所有 K 线底部新增日期滚动条

此前 K 线只能靠鼠标滚轮或拖拽缩放，看不到当前可视区间。本次在 三处 K 线（大盘面板、个股弹窗、迷你缩略图）底部都加了一条可拖动的 日期滚动条（dataZoom slider）：

  • 拖动两端手柄可框选起止日期；
  • 拖动中间滑块可平移可见区间；
  • 滚轮缩放仍可同时使用。

这样即便长期历史数据也能一键滑到想看的日期段。

2.4 支撑/阻力改为多方法共振 + 置信度

支撑位与阻力位的计算由单一方法升级为多方法共振（如前期高低点、均线、整数关口等共同确认），并在图上标注置信度，帮助你判断该价位的可靠程度，而非一个孤立数字。

2.5 龙虎榜升级

龙虎榜面板支持：按字段排序、按机构席位筛选、查看个股 N 日涨跌，便于快速锁定异动与机构动向。

2.6 界面可自由缩放

使用 pywebview 原生窗口时，支持最大化 / 最小化 / 自由拖拽缩放；未安装 pywebview 时自动回退到浏览器窗口，同样可缩放。

2.7 个股详情弹窗可自由拖动

此前弹窗居中钉死、小窗模式下会卡在屏幕中间挡住内容、还只能拖动外面的大窗口。现在按住弹窗标题栏即可把弹窗拖到任意位置，小窗下也能完整看到里面的 K 线与资料；双击标题栏或关闭后再次打开会自动重新居中。同时弹窗内容超长时内部可滚动，不再被窗口边缘截断。

2.8 放大 K 线支持横向滚轮 / 滚动条平移

在个股详情里放大后的 K 线（高 460px）上，除了底部已有的日期滚动条可拖动平移外，现在鼠标滚轮也能直接横向滚动 K 线，快速左右扫看历史走势；缩放仍可通过拖动滚动条两端的手柄完成。底部滚动条拖动 + 滚轮横移，两种姿势都能平移 K 线。

三、之前版本（v2.x）简要回顾

v2.x 阶段主要完成了「数据铺满 + 面板补全」：

  • 大盘指数（8 个）、自选股、板块涨幅榜、涨跌家数、龙虎榜面板；
  • 个股分时 / K 线弹窗、界面内搜代码加自选；
  • 量比放量/缩量徽标、每 3 秒刷新。

v3.0 在 v2.x 的基础上，重点提升可读性（放大 K 线、日期滚动条）与分析深度（多方法 SR、龙虎榜升级），并把名称/版本号统一收口。

四、别人如何配置到本地运行

本程序零第三方依赖（仅标准库），任何人都能在几分钟内跑起来。有两种获取方式：

4.1 方式一：克隆仓库（推荐，便于后续更新）

git clone https://github.com/woyaozhaoxifu/stock-monitor.git
cd stock-monitor

4.2 方式二：下载 ZIP

打开 GitHub 仓库页面 → 点 Code → Download ZIP，解压后进入文件夹即可。

4.3 环境要求

  • 安装 Python 3.8 及以上（Windows / macOS / Linux 均可，官网 python.org 下载）。
  • 需要能访问公网（行情来自腾讯财经、东方财富的公开接口）。

4.4 安装与运行

在程序目录下执行：

python app.py

默认会在本机 8787 端口启动服务，打开浏览器访问即可：

http://localhost:8787

4.5 可选：原生桌面窗口

想要像普通软件一样弹出原生窗口（可最大化/最小化），先装一个包：

pip install pywebview
python app.py

已安装时自动弹原生窗口；未安装则自动回退到浏览器，功能完全一致。

4.6 配置文件 config.json

复制示例并改你自己的内容：

copy config.example.json config.json   # Windows
cp config.example.json config.json      # macOS / Linux

常用字段：

字段说明
title窗口/页面标题，默认「实时行情看板 · 詹姆斯是goat」
watchlist自选股列表，每项用 secid：沪市 "1.600667"、深市 "0.000636"（前缀 1=沪，0=深）
sectors关注的行业/概念板块
刷新间隔默认约 3 秒刷新一次

4.7 环境变量（部署/特殊场景）

变量作用
NO_WINDOW=1无窗口服务器模式（不弹原生窗，仅起 Web 服务），部署到服务器/云端时用
HOST / PORT监听地址与端口，默认 0.0.0.0 与 8787

五、在线访问（已部署版本）

仓库已包含 render.yaml（Render Blueprint）。把代码推送到 GitHub 的 main 分支后，Render 会自动构建并部署：

https://stock-monitor.onrender.com
公开链接，无需安装。 直接把上面的网址发给同事或在任意浏览器打开，就能看到实时看板；首次冷启动可能需等待十几秒（免费实例休眠后唤醒）。

六、常见问题排查

现象处理办法
端口 8787 被占用用 PORT=9000 python app.py 换端口，或关掉占用程序
页面无数据 / 空白检查本机网络能否访问公网；数据源为腾讯财经与东方财富公开接口
没弹出原生窗口未装 pywebview，执行 pip install pywebview；或用 NO_WINDOW=1 走浏览器
部署后打不开确认已推送到 main 分支触发 Render 自动构建；查看 Render 日志
