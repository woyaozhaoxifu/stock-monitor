# StockBoard · 实时行情看板

一个 **零依赖、可离线运行** 的桌面行情看板：A股 / 美股 / 港股 / 日股 / 韩股全覆盖，涨红跌绿，自带分时 / K线，支持搜索加自选。后端仅用 Python 标准库，前端是单文件 HTML + ECharts。

> 数据源：腾讯财经 `qt.gtimg.cn` / `web.ifzq.gtimg.cn`，涨跌家数基于新浪实时行情逐只统计（真实值，非估算）。
> ⚠️ 仅供学习与研究，所有数据来自第三方公开接口，**不构成任何投资建议**。

---

## ✨ 特性

- 🌐 **全市场覆盖**：A股（沪深京）、美股、港股、日股、韩股，一套配置全搞定
- 📊 **涨跌家数实时可视化**：顶部堆叠条 + 市场情绪（普涨 / 偏多 / 均衡 / 偏空 / 普跌）
- 📉 **个股涨跌榜**：全市场实时扫描，涨幅 / 跌幅 TOP15，点击直达 K线
- 📈 **分时 / 日K / 周K / 月K**：K线带成交量副图，自动识别美股后缀
- 📐 **指标线**：MA5/10/20/60 均线 + 支撑 / 压力位（近20日低/高点），可开关
- ✏️ **画趋势线**：在 K线上点两个点连成趋势线，自动保存到本地，可一键清除
- 🔍 **智能搜索**：支持中文名 / 代码 / 拼音，一键加自选
- 💡 **量能判定**：用真实成交量对比昨日，给出「缩量 / 平量 / 放量」徽章
- 🪟 **原生窗口**：可选 pywebview 原生桌面窗体，否则自动用浏览器打开
- 💼 **我的持仓**：录入代码 / 成本价 / 数量，自动算市值、盈亏额、盈亏%、仓位占比；一键生成「持仓分析报告」（总体盈亏、胜率、盈亏 TOP、集中度与风险体检）。数据仅存本机浏览器，不上传
- 📦 **零第三方依赖**：核心功能只用 Python 标准库

## 🚀 快速开始

### 方式一：直接用（推荐）

```bash
# 1. 进入目录
cd stock-monitor

# 2. 运行（Python 3.8+，无需安装任何包）
python app.py
```

程序会自动在 `http://127.0.0.1:8787/` 启动，并打开窗口 / 浏览器。

> ECharts 默认从本地 `echarts.min.js` 加载；若该文件不存在，会自动回退到 CDN（jsdelivr）。想完全离线用，就把 `echarts.min.js` 放到目录里。

> 想固定关注标的？编辑同目录 `config.json`（首次运行会自动从 `config.example.json` 生成）。

### 方式二：原生桌面窗口（可选）

```bash
pip install pywebview
python app.py
```

安装 `pywebview` 后会弹出独立桌面窗口（可最大化 / 最小化 / 拖拽缩放）；未安装则自动回退为浏览器。

双击 `start.bat`（Windows）亦可一键启动。

## ⚙️ 配置说明

所有关注标的写在 `config.json` 的 `secids` 数组中，使用如下 secid 格式：

| 市场 | 格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| 沪市股票 | `1.代码` | `1.600519` | 贵州茅台 |
| 深市股票 | `0.代码` | `0.300750` | 宁德时代 |
| 美股指数 | `100.DJIA` | `100.SPX` | 标普500 |
| 美股个股 | `105.代码` | `105.AAPL` | 苹果 |
| 港股指数 | `100.HSI` | `100.HSI` | 恒生指数 |
| 港股个股 | `116.代码` | `116.00700` | 腾讯控股 |
| 日股 | `TX:jp代码` | `TX:jp6758` | 索尼 |
| 韩股 | `TX:kr代码` | `TX:kr005930` | 三星电子 |

字段含义：

- `title`：看板标题
- `refreshSeconds`：自动刷新间隔（秒）
- `market`：大盘指数区
- `watchlist`：自选股区
- `global`：全球市场分组（美股 / 港股 / 日股 / 韩股）

## 💼 我的持仓（本地私有）

看板内置「我的持仓」模块，用来管理你**自己的仓位**并生成分析：

1. 在「我的持仓」面板填写 **代码 / 名称**（支持 6 位代码或中文名/拼音搜索）、**成本价**、**持仓数量**，点「+ 添加持仓」。
2. 看板每 3 秒拉一次实时价，自动算 **市值 / 盈亏额 / 盈亏% / 仓位占比**，顶部汇总 **总市值 / 总成本 / 总盈亏 / 收益率 + 胜率**。
3. 点「📊 生成分析报告」弹出报告：总体盈亏、盈利分布（胜率）、盈亏 TOP3、仓位集中度与风险体检，并叠加当前大盘情绪。

> 🔒 **隐私**：持仓数据只存在你浏览器的 `localStorage`，**不会上传到任何服务器**。这意味着——在本机打开看的是你的持仓，在别人电脑/手机打开是各自的持仓；公开部署的链接人人可填自己的仓位，互不影响。
>
> ⚠️ 报告仅为数据统计分析，**不构成任何投资建议**。

支持 A股（沪深京）。北交所代码也能录入，但腾讯免费源对北交所的成交额/换手率字段可能为空（不影响现价与盈亏计算）。

## 🔌 接口一览（供二次开发）

| 路径 | 说明 |
| --- | --- |
| `GET /api/state` | 聚合状态：大盘 / 自选 / 全球 + 成交额 / 量能 |
| `GET /api/boards` | 板块涨幅榜（新浪行业板块） |
| `GET /api/breadth` | 涨跌家数（真实统计） |
| `GET /api/rank` | 个股涨跌榜（涨幅 / 跌幅 TOP15，全市场实时扫描） |
| `GET /api/kline?secid=&klt=` | K线（日/周/月，klt=101/102/103） |
| `GET /api/trends?secid=` | 分时 |
| `GET /api/search?q=` | 智能搜索 |
| `GET /api/quotes?codes=` | 批量取实时价（6 位代码或腾讯符号，逗号分隔），供持仓模块计算盈亏 |
| `POST /api/add_watch` | 加自选 `{secid}` |
| `POST /api/remove_watch` | 移除自选 `{secid}` |
| `POST /api/reorder_watch` | 调整顺序 `{secids:[...]}` |
